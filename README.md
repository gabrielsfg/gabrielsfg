## Featured Projects

### [Meeting Audio to Requirements: A Generative-AI Multi-Agent Pipeline](https://github.com/gabrielsfg/PFC1)
Undergraduate thesis (TCC). A multi-agent generative-AI system in Python that turns a raw stakeholder-meeting recording into formal software-requirements documentation end-to-end: transcription → personas and INVEST user stories → an IEEE 830 SRS → a domain diagram. Four specialized Claude agents (Haiku and Sonnet) coordinate over a file-based contract, with Groq Whisper speech-to-text and a reproducible evaluation harness. Processes a full 1h38m meeting for roughly US$0.72 in about 11 minutes. **Companion paper accepted at the 1st Workshop on Software Engineering for Agentic Systems (SE4AS), co-located with CBSoft 2026.**

### [Finance Control](https://github.com/gabrielsfg/Finance-Control)
Full-stack personal finance platform built as a monorepo: an ASP.NET Core 9 REST API (layered architecture, EF Core, PostgreSQL, JWT with refresh-token rotation, FluentValidation, background workers, Docker), a Flutter mobile client (Riverpod, GoRouter, Dio), and a Next.js 16 / React 19 web app featuring budgets, investments, live market data, and financial simulators.

### [Parallel Computing Performance Analysis](https://github.com/gabrielsfg/Parallel-Computing)
Benchmarking distributed vs. single-machine data processing with Apache Spark on a multi-node AWS EC2 cluster. Implemented in Python, Pandas, and NumPy.
